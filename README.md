# TAPin

Landing page statis untuk kartu NFC Google Review. HTML dipulihkan dari situs publik https://tapin-chi.vercel.app/ pada 26 September 2026 karena repository GitHub yang diberikan belum memiliki commit.

## Menjalankan

Buka `index.html` atau jalankan server statis dari folder ini, misalnya `python -m http.server 4173`.

## Deploy Vercel

Pilih framework **Other**, tanpa build command, dan gunakan direktori root sebagai output. Tidak memerlukan instalasi dependensi.

## Perubahan

- Tema cerah konsisten, termasuk ketika perangkat memakai dark mode.
- Aksen biru, merah, kuning, hijau dan latar pastel untuk seluruh bagian.
- Kartu interaktif vertikal biru–putih sesuai referensi; ilustrasi SVG tajam di layar kecil maupun besar.
- Aset konsep Higgsfield di bagian produk, disimpan lokal.
- Interaksi putar kartu, menu seluler, FAQ, navigasi dan CTA tetap tersedia.
